## 三、发现的 Bug

### 🔴 Bug 1: `StatsCards.tsx` 使用了不存在的 `prefix` 属性

**文件**: `frontend/src/components/dashboard/StatsCards.tsx` (第39行)

```tsx
<StatsCard
  title={stat.title}
  value={stat.value}
  prefix={stat.prefix}   // ← StatCardData 没有 prefix 字段！
  suffix={stat.suffix}
  ...
/>
```

`StatCardData` 接口定义（在 `types/common.ts`）只有：
```ts
interface StatCardData {
  key, title, value, suffix, trend, trendLabel, color
}
```
没有 `prefix` 字段，也没有 `StatsCard` 组件接收 `prefix` prop。
**影响**: TypeScript 编译警告，运行时 `prefix` 是 `undefined`，但不崩溃（React 忽略未知 prop）。

**修复状态**: ✅ 已修复（删除了 `prefix={stat.prefix}` 这行）

---

### 🟡 Bug 2: `trend` / `trend_label` 是写死的

**文件**: `backend/app/api/dashboard.py`

```py
StatCard(..., trend=14, trend_label="较上周", ...)
StatCard(..., trend=23, trend_label="较上周", ...)
```

所有卡片的 `trend` 和 `trend_label` 都是写死的数值和 `"较上周"`，不是真实计算的周环比。
**影响**: 显示"较上周 +14" 但实际是硬编码数，有误导性。

**建议**: 暂时隐藏 trend 或改为 `""`，等后端真的有周环比计算后再显示。

---

### 🟡 Bug 3: `ActivityItem.id` 使用索引，不是真实 ID

**文件**: `backend/app/api/dashboard.py` `_run_to_activity()`

```py
id=f"act-db-{idx}",   # idx 是 enumerate 的索引
```

每次刷新顺序可能变，且不是真实唯一 ID。
**建议**: 使用 `run.id`（PipelineRun 的主键 UUID）作为 activity id。
