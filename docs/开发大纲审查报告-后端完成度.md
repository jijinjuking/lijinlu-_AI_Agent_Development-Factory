## 八、数据基础设施差异

| 组件 | 开发计划（生产级） | 当前实现（开发简化） | 影响 |
|------|-------------------|---------------------|------|
| 数据库 | PostgreSQL 16+ | SQLite (aiosqlite) | 无 JSONB 索引优化、无并发写入、测试用 `:memory:` |
| 向量数据库 | Qdrant | 嵌入式（ContextEngine 内置） | 无法扩展、无分布式检索 |
| 缓存 | Redis 7+ | 无 | 无热状态缓存、无分布式锁、无 Streams |
| 文件存储 | MinIO (S3) | 本地文件系统 | 无法扩展、无对象版本管理 |
| 事件总线 | Redis Streams → Kafka | In-memory EventBus (Python) | 单进程、无持久化、崩溃丢失 |
| 任务队列 | Celery / Redis Streams | 内置 Scheduler | 单进程、无分布式任务分发 |

**结论：当前为单机开发模式，生产部署前需补齐 PostgreSQL/Redis/MinIO/Qdrant 四件套。**
